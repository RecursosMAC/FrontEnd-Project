# 📚 StudyLink

Plataforma académica colaborativa para estudiantes de la **FES Acatlán UNAM** enfocada en compartir apuntes, asesorías y recursos universitarios.

---

# 📖 Descripción

StudyLink es una plataforma web diseñada para mejorar la colaboración académica dentro de la comunidad estudiantil de la FES Acatlán.

La plataforma permite a los estudiantes:

- Compartir apuntes y materiales académicos
- Buscar recursos universitarios
- Solicitar asesorías entre alumnos
- Gestionar perfiles académicos
- Interactuar mediante un sistema intuitivo y moderno

El proyecto busca centralizar herramientas académicas en un solo entorno digital accesible y amigable.

---

# 🎯 Objetivos

## Objetivo General

Desarrollar una plataforma académica colaborativa que facilite el intercambio de conocimiento y recursos entre estudiantes universitarios.

## Objetivos Específicos

- Facilitar el acceso a material académico
- Promover el aprendizaje colaborativo
- Mejorar la comunicación entre estudiantes
- Ofrecer un sistema moderno de autenticación
- Centralizar recursos educativos en una sola plataforma
